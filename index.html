📘 StudyBuddy – Student Task Tracker

Simple Homework Organizer for Students

Team Members

Application Overview

StudyBuddy is a simple web application that helps students organize homework tasks in one place. Users can add, delete, and complete tasks to stay organized.

Technology Used

HTML CSS JavaScript GitHub Pages

Feature List

  • Add homework tasks
  • Delete tasks
  • Mark tasks as completed
  • Simple task list display

Future Improvements

  • Dark mode
  • Due date feature
  • Better mobile design

Technical Features

  • Built with HTML, CSS, and JavaScript
  • Runs in the browser
  • Uses LocalStorage to save tasks
